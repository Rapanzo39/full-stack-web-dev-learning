# Hamburger Menu – CSS Project 🍔

## 📌 Project Description
This is a simple hamburger menu project created using HTML and CSS.  
The menu includes navigation options such as Events, Gallery, Shortcuts, Exhibits, and Store.

## 🛠 Technologies Used
- HTML
- CSS

## ✨ Features
- Hamburger menu icon
- Navigation menu with multiple options
- Clean and simple layout

## 🧠 What I Learned
- Structuring navigation menus
- Styling menus using CSS
- Improving layout and spacing

## 🚀 Future Improvements
- Add JavaScript for smooth toggle animation
- Make the menu fully responsive
