# Animation Project

## This repo conatains two mini projects.

1. Smiley face Emoji.
2. shape chages every 1 sec with text this is box.

## 📌 Description
This project is a basic UI/animation project that displays a simple smiley face. and various shapes.
It is designed to demonstrate fundamental concepts of graphics, shapes, and basic animation.

## 🎯 Features
- Simple face design (eyes + mouth)
- Clean and minimal UI
- Beginner-friendly project
