
# JavaScript Events Practice

## About

This folder contains my practice programs related to **JavaScript Events**.
I am learning how to handle user interactions such as clicks, keyboard input, and mouse events using JavaScript and the DOM.


## Topics Covered

In this folder I have practiced:

* Click events
* Double click events
* Mouse events (mouseover, mouseout)
* Keyboard events (keydown, keyup)
* Form events
* Event listeners
* Changing styles dynamically
* Updating text using events

---

## Purpose

The purpose of this practice is to:

* Understand how user interaction works in web pages
* Learn how to use `addEventListener()`
* Practice DOM manipulation with events
* Build the foundation for interactive web applications
